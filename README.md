# StudyNook

Live site URL: https://studynook-client-six.vercel.app

StudyNook is a library study room booking site. Readers browse quiet rooms, reserve an hourly slot, and list a room they are allowed to manage.

- Browse the latest study rooms on the home page and open a listing for the full description, price, and booking count
- Search by room name and filter by amenities, floor, and hourly rate
- Book a date and hourly slot, with the total updating as the end time changes and overlapping reservations refused
- List a room you manage, then edit or delete it from the room page or My Listings
- Review every reservation on My Bookings and cancel a confirmed booking dated today or later
- Sign in with email or Google, with the session kept in an HTTP-only cookie so a refresh stays on the private page
